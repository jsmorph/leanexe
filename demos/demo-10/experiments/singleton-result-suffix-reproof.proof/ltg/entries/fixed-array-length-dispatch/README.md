# Fixed-array length dispatch

Apply the generated length-dispatch recipe only after the public `TerminatesWith` goal has become a body-level `wp` goal.  `Wasm.TerminatesWith.of_wp_entry_for (f := funcNDef) rfl` performs that conversion for a store-specific proof.  Do not substitute `Project.ProofKit.wp_entry` in this form: it applies the store-parametric entry theorem, while `of_wp_entry_for` retains the fixed initial store required by the frame hypotheses.  The recipe tactic cannot apply directly to the public theorem because its target begins at the annotated instruction region.

Use `program_spec` or `eqProgram_spec` for exact-size dispatch and `leProgram_spec` for an unsigned maximum-size check.  The `_from` tactic forms accept syntax such as `wp_fixed_array_length_le_dispatch_from hInput at 7, 8`, where `hInput : UInt64Array.At store inputPtr input`, to determine the pointer and represented array before generating frame premises.  Normalize the one local-index premise with the generated function definition only when `decide` cannot reduce the open frame expression.  When a branch starts with the exact constant result-capacity motif, the recipe also supplies a branch-specific equality and `FixedArrayCapacity.constantProgram_spec`.  Use `wp_length_dispatch [funcNDef, branchFrame, Function.toLocals, Function.numParams, ValueType.zero]` only when a capacity prefix lacks that exact match.

When the recipe supplies `<region>_function_eq`, it also supplies named valid-branch, invalid-branch, dispatch, and suffix programs.  A proof may mark the decoded body `funcN` locally irreducible at namespace scope, convert the entry goal to `Wasm.wp _ funcN _ _ _ _`, and rewrite with `<region>_function_eq` before applying the dispatch theorem.  Reduce `<region>_suffix_program` explicitly when a final branch continuation reaches the named suffix; an empty suffix otherwise remains visible as a folded `wp` goal.

Do not mark `funcNDef` irreducible, because public entry still requires its parameter, result, body, and initial-local projections.  Do not mark `funcN` irreducible unless the function equality appears in the checked recipe, because the ordinary dispatch tactic relies on definitional reduction of that body.  The package confines opacity to the complete decoded body while leaving named branch programs reducible for their capacity, allocation, loop, and result proofs.

The semantic theorem executes the represented length load, fixed-width comparison, Boolean normalization, and branch selection.  Its remaining obligations begin at the exact valid and invalid branch programs.  Apply a complete whole-function composition instead when another checked annotation already covers those branches.
