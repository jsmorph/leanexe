# Pretrained GPT-2 through LeanExe

This plan expands the [Development Plan](../plan.md).  On 2026-09-17 the
user paused proof development and requested a working pretrained GPT-2
124M model with a 128-token context.  The user approved pinned Transformers
and safetensors dependencies in the existing PyTorch environment, followed
by FP32 arithmetic and packed binary tensors for LeanExe/WASM.

## Model and comparison boundary

Preserve the original twelve-layer architecture, width 768, twelve heads,
3,072-wide feed-forward layer, and 50,257-entry vocabulary.  QKV and output
projections have biases.  The vocabulary projection shares the input
embedding.  LayerNorm uses epsilon 1e-5, and GELU uses the original tanh
formula.  Load checkpoint weights as external binary data.

The [CPU reference](../data/gpt2-124m/README.md) checks pinned file hashes
and produces text with the original tokenizer.  Compare WASM logits and
intermediate tensors against this reference.  Its first command bounds
the combined prompt and completion at 128 tokens.  Final context-boundary
and cache behavior remain open decisions.

## Compiler and runtime work

The existing binary64 intrinsics provide the pattern for binary32
arithmetic.  Add binary32 operations, conversions, and packed weight reads,
then compare Lean, IR, and Wasmtime execution.  Current array push and set
operations copy the array.  Indexed tensor construction needs one output
allocation, following the existing array-map emitter.

The host currently accepts command-line encoded arrays.  A 498 MB parameter
set requires binary file input and resident weights across generated tokens.
Measure a GPT-sized matrix multiplication before implementing all blocks.
Then compare one complete block, followed by twelve blocks and the tied
vocabulary projection.
