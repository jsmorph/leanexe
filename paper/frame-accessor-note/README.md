# Compiler-generated frame-accessor research note

This report describes the earlier compiler at its recorded source revision.  Its reproduction commands require that revision.  [The current compiler manuals](../../README.md#documentation) describe the merged system.

`main.tex` and `references.bib` produce the research note *Compiler-Generated Frame Accessors in Exact WebAssembly Proofs*.  The note reports the generated accessor interface, structured retrieval protocol, manual source-structure substitution, and fresh addition, multiplication, and XOR proof screens.  `main.pdf` is the compiled submission file.

Build the paper by running `pdflatex main`, `bibtex main`, and two more `pdflatex main` passes in this directory.  The submitted title, author, and abstract must match the PDF text and metadata.  The review record documents the technical, prose, and rendered-output checks applied to the submitted version.

marXiv published the fifth reviewed version as [marXiv:2608.00034](main.pdf).  The first four accepted versions received thirty-seven editorial remarks in total, and the fifth received none.  `review-notes.md` records the evidence review and the changes made in response to each editorial round.
