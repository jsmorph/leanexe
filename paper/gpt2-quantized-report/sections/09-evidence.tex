\subsection{Reproduction procedure}

The repository's \src{DEVELOPING.md}{development instructions} fix the native and proof toolchains.  The \src{training/gpt2/README.md}{GPT-2 training and export instructions} describe the checkpoint and Python environment.  The quantized \dataref{README.md}{evaluation guide} gives export, compile, reference-comparison, completion, and benchmark commands.  All Lean, Lake, and compiler commands use \code{tools/leanrun} under the serialized resource limits.  The exact-binary package can be checked with the following command, written over lines for readability:

\begin{quote}\small\ttfamily
tools/artifact-proof.js check \\
proofs/artifacts/gpt2\_quantized\_cached/\\
\longcode{9082c12c3b73aa6998a6d8ca0d97b509710e8a035afbf93587d80659ce773075}/\\
program.wasm \\
Project.Gpt2QuantizedCached.ArtifactTranslation
\end{quote}

The directory and filename in that display form one path argument.  The paper's companion reproduction instructions preserve the executable command without line breaks inside arguments.  The package manifest fixes the embedded-byte definition, decoder and validator theorems, translated program, behavioral declarations, and verifier identity.  The focused source check uses \code{tools/talos-proof.js check gpt2\_quantized\_cached}.

Export with \code{quantized.py export-model --scheme group64} recreates the scheme-two weight file.  The cached test, text comparison, and benchmark scripts accept \code{--grouped} and an explicit \code{--wasm} path.  The recorded benchmark uses \code{--repetitions 3}.  Original and later certificate records preserve the capture commands, native checker commands, source digests, data digests, and output logs.  Raw captures generated under \code{build} are reproducible from those scripts.  Compressed profiles and forward-bound numerators remain in the tracked evidence directory.

The companion \code{evidence/inventory.json} records the content hashes of every source and data file selected for the report.  Its summary script recomputes the reported agreement counts, certificate counts, storage reduction, and runtime ratio from the retained JSON.  These checks validate the report's use of evidence.  Rechecking Lean theorems or rerunning inference uses the repository commands above and remains a separate operation.
