# Record array read

Use this entry when a hint has rule `element index` or `record field read`, or when a function reads or measures an `Array` of a structure, sum, enumeration, or `Bool`.  Such an array is stored as `flatWords xs`: each element's components in order, one word each, as `Value.word` gives them, so with `k` components per element, component `j` of element `i` is word `i * k + j`.  The compiler accepts a read only when every component of the element type's `Inhabited` default is 0, which is what a read past the end yields.

For `k > 1` the compiler assigns the position to an `element index` local, then each component it needs to a local, as `ite (ltU idx 2^29) (read xs (idx * k + j)) 0`, wrapped in `ofBits` for a float.  The guard keeps `i * k + j` from wrapping, since every stored array has fewer than `2^29` words.  `flatWords_read` states that this word is component `j` of `xs[i.toNat]!`.  Its premises are the component count of the element type (`fun _ => rfl`), the bound on `j`, the default's words (`List.replicate k 0`), and the array's size bound from `UInt64Array.At`.  For `k = 1` the read is the plain `read xs i` of `array read`, and `flatWords_getElem!_one` rewrites its word.  A `size result` divides the length word by `k`, and `flatWords_count` gives `xs.size.toUInt64`.

Prove a function by `Stmt.run_triple` and one `simp` call as in `straight-line-run`, with `Expr.readValue_at hW` for the array.  Split on `i < 536870912` for each guarded read and simplify the `flatWords_read` fact and the goal with the same lemmas, so that both sides take the same form, then close with `simpa using hRead`.  `Project.Grids.density_implements` is the worked example, and `energySum_implements` reads two elements.  Inside a loop or a build, where the index is below the array's length and so below the guard, `Expr.readValue_record` gives the read's word directly, as a `simp` fact with the pointer premise; `totalDensity_implements` uses it in a `LeanExe.loop` over the indices, the form the compiler accepts for a fold over an array of records.  A Flat instance for a `Bool` field uses `cond`, which keeps the Bool out of a `Decidable` instance argument that `simp` does not rewrite.
