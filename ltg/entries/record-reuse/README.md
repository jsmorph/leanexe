# Record reuse

Use this entry when a hint has rule `slot store`, `record reuse`, or `move`.  A parameter of a recursive type is owned when the result returns it or places it or one of its children in a constructor; its theorem states the argument as `Moved α`, whose `moves` lists every record pointer of the value (`Node.pointers`).  In the record branch of a match on an owned value, a constructor of the same type rewrites the matched record: the compiler computes the value of every field other than the record's own field in the same slot, then stores each into its slot (`slot store`), and the constructor's value is the record's pointer (`record reuse`).  An owned variable used as a value moves (`move`).  The compiler rejects a record branch that neither only reads the record nor rebuilds it with every child moved into the result, since releasing part of a value is not supported yet.

`Project.Trees.setKey_implements` proves the template for one word slot.  `Func.implements_moves` reduces `Implements` to a triple.  `NodeOwned.writeWord` gives, for a write of a word into a word slot of an owned record with pairwise disjoint blocks, `Memory.WritesRange` over the slot, `Heap.At` in the new store, the record with the new word, and its blocks unchanged.  The record's pointer heads `Node.pointers`, so every region apart from the moved blocks is apart from the record's block, which contains the slot, and keeps its bytes.  For the result's part of the region clause, rewrite the result's blocks to the argument's blocks with `Node.pointers_blocks`.  Name every intermediate state with `let`, as in `node-match`.
