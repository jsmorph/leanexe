# Consumed recursion

Use this entry for the internal function of a recursive definition that returns a tree and consumes a tree parameter.  The compiler first borrows each tree parameter that every self-call passes unchanged in its own position and that the body moves nowhere else.  It makes the other tree parameters owned in the greatest fixed point of the mode rule: each starts owned at the self-calls, and each round keeps those the body still moves.  A self-call at an owned position must receive an owned value that occurs once in the call, which the call moves, and a self-call at a borrowed position may receive an owned value, which the caller lends for the call (see the `function-call` entry).  The internal function rejects an owned parameter that some path does not move.  In the record branch, the constructor rewrites the matched record after the self-calls, as in `record-reuse`.

`Project.Trees.incr_rec` is the worked proof.  `Func.rebuildRecursion` reduces `Rebuilds` for every argument to the body's triple under the hypothesis for smaller arguments.  Each self-call is `Stmt.selfCall_rebuilds`, whose result state is a function of the unknown result pointer; `Triple.of_forall` carries its existential into the next statement.  The first call's premises come from the argument's ownership and disjointness.  The second's follow from the first call's `Heap.Rebuilt` through `Heap.Rebuilt.keepNode`, which keeps the sibling subtree with the same blocks.  After the three slot stores, which write only the record's 24 bytes, `Heap.Rebuilt.node` gives the result.  `Func.entry_rebuilds` derives `Implements` for the entry: the region clause of `Heap.Rebuilt` is `Implements`'s frame in its `Heap.Keeps` form (see the `region-frame` entry).  Pass each call's parameter count as `(by rfl)`, so that it is checked after the call's arguments are known.

`Project.Trees.insert_rec` adds three things.  A constructor with no free matched record allocates a record (`new record`, `Stmt.record`); `Stmt.record_spec` gives `Heap.NewRecord`, which the proof turns into `Heap.Built` for the one-node tree and then into `Heap.Rebuilt` by `Heap.Built.rebuilt`.  An `if` whose value is a tree is a conditional statement whose branches assign a fresh local (`node branch`, `branch value`, `if result`); both branches must move the same owned values.  A path that rebuilds one child passes `Heap.Rebuilt.refl` for the other child to `Heap.Rebuilt.node`, and a path that changes nothing is `Heap.Rebuilt.refl` of the whole tree.  When a step names the store with `Triple.of_forall`, substitute the step's store variable (`subst s st`), not the initial store, which later statements still name.

`Project.Trees.addAll_rec` borrows its first tree and passes it to both self-calls.  `Project.Trees.addAll_args` builds each call's premises: the borrowed tree, the consumed child, and `Separate` between the child's blocks and the borrowed tree's slot regions, which follows from the parent's.  `Heap.Keeps.nodeBorrowed`, applied to the first call's region clause, keeps the borrowed tree with the same slot regions, so the proof reads its root key from the store after that call and passes the tree to the second call.  `Project.Trees.slotRegions_pos` gives the slot regions the positive lengths that the region clause requires.
