# Consumed recursion

Use this entry for the internal function of a recursive definition that returns a tree and consumes its tree parameter.  The compiler makes such a parameter owned in the greatest fixed point of the mode rule: every tree parameter starts owned at the self-calls, and each round keeps those the body still moves.  A self-call at an owned position must receive an owned value that occurs once in the call, which the call moves.  The internal function rejects an owned parameter that some path does not move.  In the record branch, the constructor rewrites the matched record after the self-calls, as in `record-reuse`.

`Project.Trees.incr_rec` is the worked proof.  `Func.rebuildRecursion` reduces `Rebuilds` for every argument to the body's triple under the hypothesis for smaller arguments.  Each self-call is `Stmt.selfCall_rebuilds`, whose result state is a function of the unknown result pointer; `Triple.of_forall` carries its existential into the next statement.  The first call's premises come from the argument's ownership and disjointness; the second's follow from the first call's `Heap.Rebuilt` through `Heap.Rebuilt.keepNode`, which keeps the sibling subtree with the same blocks.  After the three slot stores, which write only the record's 24 bytes, `Heap.Rebuilt.node` gives the result.  `Func.entry_rebuilds` derives every clause of `Implements` for the entry: `keepBorrowed` and `keepOwned` keep the caller's arrays apart from the consumed blocks.  Pass each call's parameter count as `(by rfl)`, so that it is checked after the call's arguments are known.
