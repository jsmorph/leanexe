# Array read

Use this entry when a hint has rule `array read`.  The compiler translates `xs[i.toNat]!`, for an `Array UInt64` variable `xs` and a `UInt64` term `i`, to `Expr.read`, which evaluates the position, saves it in a scratch local, compares it with the length word, and loads the element or yields 0.  Lean's `xs[i]!` panics out of bounds and returns the default 0, so the compiled read and the source agree on every input.  Expressions read memory: `Expr.eval` takes the memory as an argument, and only statements write it.

`Expr.eval` unfolds a read to `Expr.readValue`, which `simp` leaves folded, and `Expr.readValue_at hArray` evaluates it to `xs[k.toNat]!` when the array local holds the pointer.  Pass `Expr.readValue_at h` for each array, with `h` from `Heap.Borrowed.values`, to the `simp` call that computes a statement's effect; `simp` discharges the pointer premise from the state.  `Expr.read_spec` states the same fact for a position given by its evaluation, for use outside `simp`.
