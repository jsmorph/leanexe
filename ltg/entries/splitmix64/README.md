# SplitMix64 generator

Use this entry when a program draws pseudorandom numbers.  `LeanExe.Examples.Prng.splitMix state` is one step of Sebastiano Vigna's SplitMix64 (https://prng.di.unimi.it/splitmix64.c): it adds `0x9e3779b97f4a7c15` to the state and returns the new state and the mixed word, with arithmetic modulo `2 ^ 64`.  `unitFloat x` is `(x >>> 11) / 2 ^ 53`, a float in `[0, 1)`, which is exact.  A program compiles the two definitions into its own module next to its other functions and threads the state through its calls.

`splitMix_pure` and `unitFloat_pure` take the module's function list and the index of the compiled function, with a proof that the list holds `prng.splitMix.ir` or `prng.unitFloat.ir` there, usually `rfl`.  The compiled form does not depend on the module, because neither function calls another.  The proofs step through the straight-line statements with `Stmt.run_spec`, as `straight-line-run` describes; `U64Op.apply` evaluates the xors, shifts, and products, and `F64Bits.toBits_div` with `F64Convert.toBits_toFloat` the conversion.  `prng.wasm` exports both functions, and `tests/prng/compare.py` checks it against the reference algorithm.
