# WGSL kernel text and dispatch

Use this entry for a WGSL kernel.  `Project.WGSL.Module.print` prints a kernel in a restricted format, one space or newline between tokens, every number as eight hexadecimal digits, and every binary expression in parentheses, and `Module.parse_print` proves that `Module.parse` reads the text back as the kernel when its indices fit in eight digits.  `Module.invoke` runs one invocation on the read-only buffers and returns its stores to the read-write buffer, which it may not read; `Module.dispatch` applies the stores of invocations `0` to `count - 1` in order; and `Module.RaceFree` states that distinct invocations store to distinct words, which makes the order irrelevant under WGSL's memory model.

A kernel's buffers hold Wasm arrays of 64-bit words as 32-bit words (`arrayWords`), and a `u64` value is a `vec2<u32>` pair.  `readLow b k len` reads element `k` of buffer `b` with the index clamped into the buffer, so the access never leaves it, and `readLow_eval` proves that it gives element `k`'s low half below the length and 0 otherwise; `lt64_eval` proves the pair comparison.

`Project.WGSL.scaleKernel_dispatch` is the worked proof.  One `simp` call over the whole invocation times out, so `scaleKernel_invoke` proves one lemma per statement, with the environment after each `let` named and the buffer contents abstracted behind hypotheses (`arrayWords_floats`) so that `simp` never unfolds `arrayWords`.  When a hypothesis states the value of a subexpression, `generalize` that subexpression before `simp`, which otherwise unfolds it.  State `UInt32` facts through `toNat` (`UInt32.toNat_add`, `toNat_mul`, `toNat_sub`, `toNat_div`, `toNat_ofNat'`) and close them with `omega`, since `simp` rewrites `UInt32.ofNat (2 + 2 * n)` into `2 + 2 * UInt32.ofNat n`.  `scale_fold` carries the output through the invocations with an invariant on each word, and `foldlM_some` turns the dispatch's `foldlM` into a `foldl`.
