# Recursion with calls and a depth guard

Use this entry when a hint has rule `recursive entry`, `depth guard`, or `recursive call`.  A definition in a module list that calls itself other than in tail position, such as `size (node l k r) = size l + 1 + size r`, compiles to two functions.  The entry `f`, at its listed index, calls the internal function `f.rec` with the parameters and depth 0 (`recursive entry`).  The internal function follows the listed functions: it traps at `unreachable` when the depth exceeds 999 (`depth guard`), and each recursive call passes the depth plus one (`recursive call`).  A recursive call may appear at the top of the body or in a branch of a match on a value of a recursive type, where its statement runs only on that branch.  The compiler rejects an internal function with more than 24 values in its frame, so that the limit stays below the depth at which Wasmtime's default stack overflows.  The depth test in `tests/modules/run.sh` checks this with `KeyTree.wide`, a 24-value function.

`Keeps m idx f x` states the internal function's specification: at any depth, from a store with the allocator invariant and arguments that represent `x` as borrowed, a call aborts or keeps the store and returns `f x`.  The depth needs no bound in the proof, since `ReturnsOrAborts` allows a trap at `unreachable`.  `Func.recursion` proves `Keeps` for every argument by strong induction on a measure, usually `sizeOf`: the obligation is a `Triple` for the body under the hypothesis that `Keeps` holds for smaller arguments.  `Stmt.selfCall_spec` discharges each recursive call from that hypothesis; the call's argument values must represent the smaller argument, which a child's `NodeBorrowed` fact gives.  `Func.entry_implements` turns `Keeps` into the entry's `Implements`.

`Project.Trees.treeRec` packages the body of a fold over `KeyTree`: the guard, a constant for a leaf, and for a node the field loads, two recursive calls into locals 6 and 7, and a combining statement whose effect is its one premise.  `size_rec`, `sum_rec`, and `height_rec` apply it in 10 to 30 lines each.  Name each state with `let` and close set operations whose locals end in `List.replicate extra` with `simp` and `omega`, since `State.set?` tests an index against the locals' length.
