# Checked continuing array-fold body

Use `FixedArrayFoldBody.continuingGuardedProgram_spec` when an array-fold recipe supplies a continuing traversal program, a guarded-back-edge program, compiler-derived scalar evaluator equations, and a loaded-frame equality.  The theorem executes the false traversal-guard edge, loads the represented input element, and then applies the descriptor-guided body, condition, scalar continuation, and back edge.  Its exit and repeat callbacks accept the caller's postcondition, so the theorem contains no particular fold operation, invariant, measure, or formal specification.

The generated `<region>_continuing_loaded_frame_eq` declaration identifies the result of the shared indexed loader with the scalar frame used by the compiler-generated body theorem.  Pass that equality with `<region>_body_eval`, `<region>_condition_eval`, and `<region>_step_continuing_eval`, while the named step program supplies the exact guarded program.  Keep `ArrayFold.foldPrefix_succ`, invariant reconstruction, and measure decrease in the callback because they express application semantics rather than the compiler's emitted control shape.

Supply every structural and dependent premise by name: `hValues`, `hArrayLocal`, `hIndexLocal`, `hStopLocal`, `hIndexValue`, `hContinueGuard`, `hItem`, `hInput`, `hIndex`, `hLoaded`, `hStepProgram`, `hBody`, and `hCondition`.  Lean may infer `hItem` or `hIndex` from later dependent premises and shift positional tactic bullets into unrelated goals.  Fix `module_`, `env`, `st`, and `frame` when the callback postcondition otherwise allows Lean to generalize those parameters, and let Lean infer only `Q`.  Convert generated `U64State` values with `.toState`, unfold the generated continuing-frame abbreviation only in `hLoaded`, and rewrite with `<region>_step_continuing_eval` directly instead of simplifying the generic evaluator.

State parameter, internal-local-length, empty-value-stack, and required getter lemmas immediately after defining a proof-local fold frame.  These facts are usually `rfl`, but naming them prevents elaboration from expanding the frame before a suffix or body theorem can match its premises.  Pass required getters as named arguments at composition boundaries, and change a generated array predicate to `UInt64Array.At` when the two definitions are definitionally equal.

This composition addresses the repeated boundary between `FixedArrayTraversalInput.continuingProgram_spec` and `ScalarTransition.guardedBackEdgeProgram_spec`.  Demo 10 first exposed the boundary when the enclosing loop step exhausted one million heartbeats and required a 155-line local helper.  Fresh fixed-artifact proofs retrieved and used the shared theorem for Demo 10's wrapping multiplication and Demo 9's wrapping addition, and separate package verification accepted both exact artifacts.  The Demo 9 run was slower than its guarded-back-edge screen and had mixed proof-size results, so promotion records cross-operation applicability and checked retrieval rather than a timing claim.
