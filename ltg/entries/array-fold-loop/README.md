# Array fold loop

Use this entry when a hint has rule `array-fold-loop`.  The compiler translates `xs.foldl g init`, for an `Array UInt64` or `Array Float` variable `xs` and a `UInt64` or `Float` accumulator, to two statements at the start of the function body: an assignment of `init` to a fresh accumulator local, with hint `fold start`, and `Stmt.fold elementType array acc index length element body`, where `elementType` is `.u64` for an `Array UInt64` and `.f64` for an `Array Float`, and `body` is the translation of `g acc element`.  The value that contained the fold reads the accumulator, with hint `fold result`.  The four fold locals follow the parameters and any earlier fold's locals, in the order accumulator, index, length, element.

`Stmt.fold_spec` proves the fold from a precondition that fixes the store and the state, `store = initial ∧ state = before`.  Its premises are the distinctness of the five locals and their bounds, by `decide`; enough locals in `before` to cover the scratch index; `UInt64Array.At initial ptr xs`, which `Heap.Borrowed.values` provides for a borrowed argument; the pointer and the starting accumulator in `before`; and `hBody`, which says the body evaluates to `g a e`.  The fold function `g` works on words: an `f64` accumulator holds a bit pattern, and the element local holds `elementType.ofBits e`, which is `.f64 e` for an `Array Float`.  For a body that reads only the accumulator and the element, prove `hBody` with `simp [Expr.eval, hA, hE, U64Op.apply]`, or with `F64Op.apply` for a float body.  The `float-array-fold` entry converts a fold over bit patterns to the source fold.  A body that reads another local gets its value from the `State.Frame` premise.

To reach the fold's precondition, name the state after the preceding statements explicitly and use `Stmt.seq_spec` with a middle predicate of the same fixed form.  `Triple.of_forall` converts any precondition into this form.  After the fold, `State.Frame` gives every local below scratch that the fold does not write, and `Expr.eval_frame` gives the same for any expression.  `Project.SumArray.sumArray_implements` is the worked example: the per-program proof is 20 lines.
