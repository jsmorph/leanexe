# Array size

Use this entry when a hint has rule `array-size`.  The compiler translates `xs.size.toUInt64`, for an `Array UInt64` or `Array Float` variable `xs`, to `Stmt.arraySize dst src`, a load of the length word at the array's pointer into a fresh local `dst` at the start of the function body.  The value that contained the size reads `dst`, with hint `size result`.  Lean defines `Nat.toUInt64` as `UInt64.ofNat`, so the local holds `UInt64.ofNat xs.size`.

`Stmt.arraySize_spec` proves the load from a precondition that fixes the store and the state.  Its premises are `UInt64Array.At` for the array, which `Heap.Borrowed.values` provides for a borrowed argument, the pointer in the source local, and the destination's index below the state's length.  The postcondition keeps the store and gives the new state as `before.set? dst`, so take the new state from `State.exists_set?` and match it with `Option.some.inj`.  For an `Array Float`, the stored words are `xs.map Float.toBits`, and `Array.size_map` gives their size as `xs.size`.  `Examples.SumCount.sumCount_implements` and `Examples.Mean.mean_implements` are the worked examples.
