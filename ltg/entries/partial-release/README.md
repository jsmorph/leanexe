# Partial release of a consumed tree

Use this entry when a hint has rule `release child`, `clear slot`, or `release record`.  In the record branch of a match on an owned value, the matched value counts as moved from the start of the branch.  A constructor that rewrites the record computes its values, releases each child of the record that is still unmoved (`release child`), then stores its values.  A branch that takes some children without rewriting the record assigns its value, stores 0 into each moved child's slot (`clear slot`), and releases the record (`release record`), whose mask then frees only the children left in it.  Every branching compares the moved values and the rewritten records of its branches.

`Project.Trees.dropRight_implements` and `Project.Trees.leftChild_implements` are the worked proofs, and `Func.implements_rebuilt` reduces each to a triple that ends in `Heap.Rebuilt`.  For a released child, `Stmt.releaseNode_rebuilt` states the release as a rebuild to the null pointer, so `Heap.Rebuilt.node` takes it as the rebuilt child, with `Heap.Rebuilt.refl` for the kept child (`Heap.Rebuilt.dropRight`).  For a returned child, `NodeOwned.clearLeft` gives the record with a null slot 0 and the allocator invariant after the clear, `Stmt.releaseNode_spec` releases that record, and `Heap.Rebuilt.leftChild` keeps the returned child through both steps.  The release function is at index 1 with type index 1.
