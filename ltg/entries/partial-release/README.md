# Partial release of a consumed tree

Use this entry when a hint has rule `release child`, `clear slot`, `release record`, `release unmoved`, or `release owned parameter` for a tree.  In the record branch of a match on an owned value, the matched value counts as moved from the start of the branch.  A constructor that rewrites the record computes its values, releases each child of the record that is still unmoved (`release child`), then stores its values.  A branch that takes some children without rewriting the record assigns its value, stores 0 into each moved child's slot (`clear slot`), and releases the record (`release record`), whose mask then frees only the children left in it.  At the end of an `if` or a match whose value is a tree, each branch releases what another branch consumes and it does not: when another branch rewrites the matched record, the branch clears its moved children's slots and releases the record, and it releases each other owned tree it has not moved (`release unmoved`).  The branches then agree on the moved values and the rewritten records.

`Examples.Trees.dropRight_implements` and `Examples.Trees.leftChild_implements` are the worked proofs, and `Func.implements_rebuilt` reduces each to a triple that ends in `Heap.Rebuilt`.  For a released child, `Stmt.releaseNode_rebuilt` states the release as a rebuild to the null pointer, so `Heap.Rebuilt.node` takes it as the rebuilt child, with `Heap.Rebuilt.refl` for the kept child (`Heap.Rebuilt.dropRight`, an instance of `Heap.Rebuilt.rightChild`).  For a returned child, `NodeOwned.clearLeft` gives the record with a null slot 0 and the allocator invariant after the clear, `Stmt.releaseNode_spec` releases that record, and `Heap.Rebuilt.leftChild` keeps the returned child through both steps.  The release function is at index 1 with type index 1.

`Examples.Trees.keepIf_implements` releases the tree in one branch of an `if`: `Heap.Rebuilt.refl` gives the branch that returns it, and `Stmt.releaseNode_rebuilt` the branch that returns a leaf.  `Examples.Trees.trim_implements` has an `if` inside a record branch whose `else` branch rewrites the record as `dropRight` does, so its `then` branch clears slot 0 and releases the record as `leftChild` does.  The two branches use `leftChild_node` and `Heap.Rebuilt.dropRight`.

A path of a pair-valued `if`, or of a case split on a structure or an enumeration, releases each owned tree that it does not move (`release owned parameter`), through the release function and the child masks, after the path stores its results.  `Examples.Trees.sizeDrop_implements` is the worked proof: `Stmt.releaseNode_rebuilt` releases the tree on the path whose pair holds a leaf, `Heap.Keeps.rebuilt` joins the frame of the earlier call to `size`, and `Heap.Rebuilt.wordPair` gives the owned pair of the word and the rebuilt tree.
