# List cell

Use this entry when a hint has rule `list cell` or `empty list`.  The compiler represents a `List UInt64` as a pointer word: `[]` is the constant 0, with hint `empty list`, and `x :: xs` is a record of two slots, the word `x` and the pointer to `xs`, with kind 1, width 2, and child mask 2.  The constructor with fields of a recursive type, such as `Words.cons x w`, is a cell too, with child bit `i` set for each field of a recursive type, and its fieldless constructor is 0.  A cell may appear only as the next state of a loop, where it runs once per iteration.  The compiler translates it to `Stmt.record dst [x, xs] 2` into a fresh local, with hint `list cell`, followed by the state copy.  `Stmt.record` calls `alloc` for 16 payload bytes, stores kind, width, and mask over the header that `alloc` wrote, and stores the slots with `Stmt.storeSlots`.

`Stmt.record_spec` proves the template from the precondition `store = initial ∧ state = before` and concludes `Heap.NewRecord` for the heap after the allocation.  Its value premise is a `List.Forall₂` with one obligation per slot, proved as for `Stmt.arrayLiteral_spec`; the second slot's value is the state local, whose value comes from `State.Holds` and the frame premise.  `NewRecord.region` says that every region of the old heap keeps its bytes, stays a region of the new heap, and lies apart from the new block, which is how earlier records and the caller's arrays survive the allocation.

A loop that builds a list carries `Heap.Built heap initial heap' store p (encodeList xs)` in its invariant: the list is owned at `p`, its blocks are pairwise disjoint, every region of the starting heap keeps its bytes, stays a region, and lies apart from the list's blocks, and the memory limits are unchanged.  `Heap.Built.null` starts it from `heap.At`, and `Heap.Built.cell` takes it across one cell from `Heap.NewRecord`.  At the end, `Built.region` gives the region clause of `Implements` in its `Heap.Keeps` form, and `Built.owned` and `Built.disjoint` give `Represent.owned` for the result.  The invariant is stated over `Node`, so a user recursive type reuses it with its own cell lemma.  `Project.Lists.listRange_implements` is the worked example, through `Stmt.loop_inv` with the state local as the loop's one variable: 57 lines.
