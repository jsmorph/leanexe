# Calls that return scalars and one array

Use this entry for a composite function whose calls return arrays of records or tuples of scalars and one array, such as `UInt64 × Float × Array Cell`.  `OneArray` describes such a type: an owned value is its scalars followed by the pointer of an owned array of words, and that array's block is the value's only block.  Instances cover `Array UInt64`, arrays of a `Flat` type (their words are `flatWords`), and a scalar paired with a `OneArray` type.  An array of records that the caller hands over has type `Moved (Array α)`.  Its borrowed form is the owned words, and its moves are its pointer.

A proof starts from `Live.start` or, when the function consumes arguments, `Live.start_moved` with those arguments as the temporaries.  `Live.callOne` (or `Live.callOne_seq` with a continuation) runs a call: the consumed temporaries come first in the `Live` list, `hMoves` states that the call moves exactly their pointers, and `hReads` that the regions it reads lie apart from their blocks.  For an argument tuple, state `Represent.moves` and `Represent.reads` with `rfl` on the explicit tuple and value list.  `simp` does not reduce the instance's `take` and `drop`.  `Live.callScalar_seq` runs a call with a scalar result, such as a check over a borrowed grid, and `Stmt.ite_test` splits on a test that leaves the state.  `Live.releaseFirst` and `Live.releaseSecond_last` release a temporary, and `Live.finish_results_one` closes the body once one temporary remains and the result expressions evaluate to the scalars and its pointer.

Give membership proofs for `Live.tempsOwned` with the explicit pair and `by simp`: an argument left as `_` with `List.mem_cons_of_mem _ ...` made elaboration time out.  [`Examples/Euler/Steps.lean`](../../../Examples/Euler/Steps.lean) holds the worked examples, from `finishStep` to `solve`.
