# Record array build

Use this entry when a hint has rule `record build`.  The compiler translates `LeanExe.build n g`, for a structure, sum, enumeration, or `Bool` element type of `k` components, to `Stmt.buildRecords dst limit index count body elements`.  The template checks that `n · k` words fit below `2^29`, allocates `8 · (n · k + 1)` bytes, stores the length word `n · k`, and for each index runs `body`, which leaves the components of `g i` in locals (hint `component`), then stores the `k` expressions `elements` as words `i · k` onward.  Each element expression is `Expr.word c t`: `get c` for a word local and `toBits (getF c)` for a float local.

`Stmt.buildRecords_spec` gives `Heap.NewArray` for `flatWords (LeanExe.build n g)`, which `Represent (Array α)` uses for an owned array of records, so the result clause of `Implements` follows from `hNew.owned` as for `Stmt.build_spec`.  Its premise for each index is a `Triple` for `body` that keeps the store, writes only the listed locals, and ends where element expression `j` yields word `j` of `g i` (`Expr.Yields`, which `Expr.yields_get` and `Expr.yields_toBits` prove from the local's value).  Pass the element list and the scratch index explicitly, and the starting state as `before` when the template follows other statements, since `elements` determines the length the hypotheses mention.

Prove the per-element `Triple` with `Stmt.run_triple` and an explicit final state: one `simp` call proves the run equation, `State.Frame.update` the frame, and the element goals follow by cases on `j`.  Rewrite the expected words first with a lemma such as `scaledElement_words`, which states `(Scalar.values (g i)).map Value.word` as a list of bit patterns.  Otherwise `simp` pushes the map inside the list lookup, and closing the goal by `rfl` unfolds binary64 operations such as `IEEE64.convertI64U` and does not finish.  For reads of a borrowed array of records in `body`, give `simp` facts from `Expr.readValue_record` stated with the field's bits (`record-read`).  `Examples.Grids.scaled_implements` is the worked example.  `ramp_implements` builds from the index alone.
