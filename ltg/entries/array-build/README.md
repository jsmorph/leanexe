# Copying array template

Use this entry when a hint has rule `array set`, `array build`, or `array copy`.  The compiler implements `xs.set! i.toNat v` on an array variable, `LeanExe.build n f`, and the return of an array variable with `Stmt.build dst limit index count element`: it evaluates the count into `limit`, allocates `8 * (n + 1)` bytes, stores the length, and stores the value of `element` at each index held in `index`.  For `set!`, the position and the value go into locals first, and the element is `if index = position then value else xs[index]`, a bounds-checked read.  The template copies, so it never changes an argument, and in-place update waits for ownership.

`Stmt.build_spec` gives a new owned array equal to `LeanExe.build n f`, with the same allocation facts as `Stmt.arrayLiteral_spec`.  Its element premise quantifies over any store in which the borrowed arrays are still laid out, so an element read of a borrowed array uses `Expr.readValue_at` with that premise.  `set!_eq_build` equates `xs.set! k.toNat v` with the template's array, by `Array.ext` and core's `getElem_setIfInBounds`.  The allocation bound of `Implements` depends on the input, for example `48 + 8 * (xs.size + 1)`.  `Project.Clob.fillLevel_implements` is the worked example.
