# Theorems about an emitted file

A file theorem states that the `.wasm` file that `tools/Emit.lean` wrote holds the encoding of a module, so that the module's theorems describe the file without trust in the emission step.  Each module of `tests/verified/modules.txt` that has `p.bytes` has a file module, and a module that joins that registry needs one.  The file module reads the file at elaboration, so it stays outside the import graph, and the driver checks it after it writes the file.

Write the file module beside its module, as `File.lean` in a directory of its own or as `BASEFile.lean` beside other modules, with an import of the module and of `LeanExe.Pipeline.FileBytes` and one command, `file_theorems NAME p "PATH" from B₁, …, Bₙ`.  `PATH` is relative to the directory of the source file, and `LeanExe.Pipeline.elabFileTheorems` states `NAME_file`, that `encode p.module` is `.ok` of the file's bytes, and `NAME_file_decode`, that those bytes decode to `p.module`, and prints the axioms of both.  `B₁` must state `∃ bytes, encode p.module = .ok bytes ∧ decode bytes = .ok p.module ∧ …`, possibly as the first part of a conjunction, as `p.bytes` of `verified_compile` does, and the decoding goes through `LeanExe.Pipeline.decode_eq_of_file`.  List every byte theorem of the module after `from`, since the proof of `NAME_file_decode` contains them all and its axiom report then covers them.  Register the module as `name:TheoremModule:FileModule` in `tests/verified/numerics.txt`, the file-theorem registry that the driver reads.

A theorem whose decoding names some module rather than `p.module`, such as `Demos.Gpt.gpt_bytes`, cannot supply the decoding.  For such a module, leave `from` out, and the command proves the decoding with `Wasm.Encoding.decode_encode` and the kernel's check of the decoder's limit on locals.  A module without `p.encoded` makes the kernel evaluate the encoder through `LeanExe.Pipeline.encode_eq_of_toList`, which took 9.5 seconds for the 14 KiB of `gpt.wasm`, while the comparison with the literal bytes of `p.encoded` through `LeanExe.Pipeline.encode_eq_of_encoding` took about 0.13 seconds plus 94 milliseconds per KiB.  A module built without the reflector, such as `Verified.Examples.TailCore`, has no `p.bytes`, and `Verified.Examples.Modes.byHandModule` has no `p.module`, so neither has a file module.

The worked examples are file modules, which no module imports.  `Library/Hashing/Sha256/File.lean` takes the decoding from one byte theorem, `Library/Numerics/Float64/Sinpi/SinpiFile.lean` from three, `Examples/RunningMax/File.lean` from `compiled.bytes`, and `Demos/Gpt/File.lean` has no `from`.
