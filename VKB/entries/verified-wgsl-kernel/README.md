# A WGSL kernel through the verified compiler

A function whose body is an outer `LeanExe.build` over words, Booleans, or binary32 values compiles to WGSL through `Verified.WGSL.compile` after `verified_compile`.  A dispatch theorem states that the kernel writes the Lean function's result into the output buffer and is race-free in the WGSL device model.  Its premises bound the input arrays below `2 ^ 29` elements, require an output of the result's size with its length word written, and require enough invocations.

Define the kernel as `(Verified.WGSL.compile (e := .float32) compiled.f.func.body).get (by decide +kernel)`, and its module as that kernel's `.module`.  Prove `gpu.spec.Fits (gpu.args env) n`, with `env` the arguments as a `Verified.Env` such as `.cons a (.cons x .nil)`, by `refine ⟨rfl, ?_, ?_, hn⟩`.  The sizes follow from `change ∀ ys, Arg.array ys ∈ [the explicit arguments] → ys.size < 2 ^ 29` and `simp`.  The count follows from a `change` to the form `∃ ys, some (Arg.array …) = some (.array ys) ∧ ys.size = n` when it is an array's size, or to `some (Arg.word w) = some (.word (UInt64.ofNat w.toNat))` with `UInt64.ofNat_toNat` when it is a word.  `Verified.WGSL.Compiled.dispatch_value _ env _ (compiled.f.denote_eq …) n fits output hOut hL0 hL1 count hCover h32` then closes the goal.  A local abbreviation for the words of a binary32 array, `x.map fun v => v.toBits.toUInt64`, makes the statement match by definition.

`Verified.WGSL.lower` covers literals, variables, word, Boolean, and binary32 operations, reads, sizes, `let`, `if`, and counted loops.  It returns `none` for calls, binary64 values, and composite elements, and the proof of `get`'s premise then fails.  A function that the reflector rejects never reaches the translation.

The worked examples are `Examples.Binary32.scale32_dispatch`, `Examples.Binary32.axpyArray32_dispatch`, and `Examples.Binary32.matVec32_dispatch`, which keep the premises of the LeanExe compiler's dispatch theorems.  `Demos.Gpt32.Verified.expKernel_dispatch` and `Verified.Examples.Wgsl.scale_dispatch` keep the abstract `Fits` premise instead.

`Examples.Binary32.condMix32_dispatch` takes mixed arguments in their order, `[Arg.array …, Arg.float lo.toBits, Arg.float hi.toBits, Arg.word n]`, with the count from the array at position 0, and its conjunction of propositions lowers to `Expr.and`.
