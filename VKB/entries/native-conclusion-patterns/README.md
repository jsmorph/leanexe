# Destructuring the conclusion of a native theorem

The entry applies when a proof uses a theorem `p.f.native`, whose statement is `NativeImpl`, `NativeTablesImpl`, or `NativeStaticImpl`.  The proof obtains `⟨fd, ps, rs, hfd, hsig, hnat⟩` from the theorem and applies `hnat` to the environment, the store, the heap, the arguments, and a C memory related to the store.  The result has the form `⟨t, m', vres, final, hcall, hst', hres⟩`, where `hres` is a disjunction of a return and a trap.

After a return, the conjuncts follow this order: `StatusRel E m' 0`, then `vs` and `heap'`, `ResultRel`, `heap'.At final`, `LeanExe.Pipeline.Represent.owned`, `final.memoryCaps = store.memoryCaps`, the region clause, and `Post`.  The pattern `rcases hres with ⟨hs', vs, heap', hr, hAt, hown, hCaps, hRegion, hPost⟩ | ⟨habs, htrap⟩` names each of them.  A proof that needs only the result writes `⟨hs', vs, heap', hr, -, hown, -⟩`, whose last `-` discards every conjunct after ownership, as `LeanExe.Native.bare_of_nativeA` and `TestSupport.Native.Gcd.loop_native_init` do.

A pattern that names its last component binds the whole remaining conjunction.  Ending at `hown, hPost` makes `hPost` the conjunction of the caps, the region clause, and the postcondition, and a use of `hPost` as the postcondition alone then fails.  For a host that makes a second call, `hCaps` keeps the memory cap of the next call's premise, and `hRegion` shows that a region of the first heap apart from the moved blocks keeps its bytes and remains a region of `heap'`, which provides a borrowed input to the second call.  No proof uses `hRegion` for a second call, and `LeanExe.Native.NativeA.unique` gives the same conclusions for every execution whose trace agrees with the asserted one.

`LeanExe.Native.reqRuns_of_nativeA` shows a call repeated in every window of a loop.  It takes the return apart with `⟨hs', vs, heap', hr, hat', hown, hcaps', -, -⟩`, and its conclusion `ReqRuns` hands `heap'.At final` and the equality of `final.memoryCaps` with the caps of `nativeStore` to the next window's call, whose premises they are.  `LeanExe.Native.ctlRuns_of_nativeA` does the same for a controller, and [the entry on bare-metal C programs](../bare-metal-programs/README.md) describes the whole-program theorems that both lemmas serve.
