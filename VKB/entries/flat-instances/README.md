# Representations of structures and enumerations

A `verified_compile` definition whose parameters, results, array elements, or fields hold a structure or an enumeration compiles only when the type has a `Flat` instance, which states the words that represent it in the generated theorems.  Without one, the command stops at the first such type with ``verified_compile: the type T is not UInt64, Bool, Float, Float32, Bytes, a structure with a `Flat` instance, an array, or a pair``.

Declare `instance : LeanExe.Pipeline.Flat T R` for each type: `R` is the tuple of a structure's fields, each once and in any order, or `UInt64` for an enumeration, whose words come from `ctorIdx` or a `match`, as [the verified manual's section on records, tuples, and sums](../../../docs/verified-manual.md#records-tuples-and-sums) describes.  A structure of one field may map to that field's type, as `Examples.Grids` maps `Mass` to `Float`, and a nested structure maps through its own instance.  Put the instances in a module of their own beside the program, as `Examples/Grids/Flat.lean`, `Examples/Bools/Flat.lean`, and `Examples/Calc/Flat.lean` do, and import that module in `Compiled.lean` and in every other module whose theorems state the representation.  Every theorem then states one representation, and the program module stays unchanged.

The flattening of a type's default must be the default of its fields, which `deriving Inhabited` gives, and a read past the end of an array of records then returns the default, as Lean's `xs[i]!` does.  The cases of the registry module `exampleGrids` read past the end of arrays of `Cell`, a structure with a nested structure, floats, words, a `Bool`, and an enumeration, at positions whose word offsets do not fit in 32 or 64 bits, and the module returns Lean's results there.  The worked examples `Examples.Grids.compiled.bytes` and `Examples.Bools.compiled.bytes` compile programs whose modules hold no instance with the instances of their `Flat.lean`, and `Verified.Examples.Records.compiled.bytes` and `Verified.Examples.Enums.compiled.bytes` declare the instances beside the definitions.
