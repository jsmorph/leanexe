# A specification equality carried to a call theorem

A program often has a theorem that equates it with an independent specification, such as `compute_eq : xs.size < 2 ^ 64 → compute xs = expected xs`.  Its verified compilation has the generated `compiled.compute.trapFree` or, for a scalar function, `compiled.compute.pure`.  The goal is a theorem about one export, called from a store that meets stated premises, whose result is the specification's value without a trap.

For a function from a borrowed `Array UInt64` to an owned `Array UInt64`, apply `Examples.arrayCall` to `compiled.f.trapFree`, a lemma `∀ xs, compiled.f.bound xs ≤ B`, and `fun xs h => compute_eq xs h`.  It gives a `Runs false` statement from a store with `heap.At store`, a memory cap of at most 65,535 pages, `heap.Borrowed store ptr xs`, and `heap.Within store compiled.module B`.  It concludes the owned result, the borrowed input, the kept regions, and the rise of `top`.  Inside it, `LeanExe.ProofKit.UInt64Array.At.size_lt` discharges the equality's size premise from the input's representation, `LeanExe.ProofKit.BorrowedKept.borrowed_kept` keeps the input borrowed, and `LeanExe.Pipeline.memoryCap_le_of_caps` keeps the cap.

For a scalar function with a `pure` theorem, apply it at the argument tuple and close with `Wasm.Runs.mono`, as `Library.Numerics.Arithmetic.Gcd.gcd_call` does, where `simpa [Scalar.values] using congrArg List.reverse hv` turns `values.reverse = Scalar.values (f x)` into `values = [.i64 …]`.  `Runs` lists the arguments with the top of the stack first, so a call of `f a b` takes `[.i64 b, .i64 a]`.  Other argument shapes follow the call lemmas of the hashing modules, such as `Library.Hashing.Sha3.shake128_call`, which build `Represent.borrowed` by hand and pass `Separate.nil` and `Apart.nil` for borrowed arguments.

`p.f.implements` allows a trap whenever the function's abort flag is true, which holds for every function that returns an array, so a call theorem that excludes the trap starts from `trapFree`.  State the export's index with a theorem such as `({ name := "compute", funcIdx := k } : Wasm.Export) ∈ compiled.module.exports`, proved by `decide +kernel`, since the call theorem names a function index and a host calls an export by name.  Keep the equality in a module that imports only the program, the specification, and lemmas about the dialect, as `Examples.Increment.Proof` does, so that the verified compilation imports nothing of the LeanExe compiler.

The worked examples are `Examples.Increment.increment_call`, `Examples.Below100.below100_call`, `Examples.RemoveZero.removeZero_call`, `Library.Numerics.Arithmetic.Gcd.gcd_call`, and `Library.Hashing.Sha3.shake128_call`.  A generic call theorem over the readiness of a program's tables is planned, and this entry will point to it when it exists.
