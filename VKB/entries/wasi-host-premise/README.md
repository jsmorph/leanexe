# Hosts that satisfy the WASI premise

Every WASI theorem assumes `targetHost.Satisfies module (hostSpec host)`: the Talos host environment meets the contracts that `Verified.Wasi.hostSpec` derives from the relational host `host`.  A theorem under that premise says nothing about a host for which no such environment exists.  A reader or a later proof that must show that the premise can hold uses the two results below.

`LeanExe.Wasi.Host.Total` states that `host` permits a reply to every read and write and either accepts or rejects every exit.  `Host.Total.satisfiable` builds, for every module with the three WASI imports, an environment that satisfies `hostSpec host`, from an oracle that chooses a permitted reply, through `Verified.Wasi.OracleHost.env_satisfies`.  Conversely, `Host.Answers.of_satisfies` shows that every satisfying environment answers each request that the one-iovec ABI can express with its payload at address 16, which `Host.Answers` states: reads of capacity at most `2^32 - 16`, writes of at most `2^32 - 16` bytes, and every 32-bit exit status.  `Host.Total.answers` derives the second condition from the first.

State the result as a sufficient condition and a necessary one.  `Host.Total` is sufficient and `Host.Answers` is necessary, and neither is exact.  The journal's first account said that the premise excludes exactly the hosts that leave a request without a reply, and the review of 2026-10-26 corrected it to this pair.  The scripted host of the WASI tests is one such oracle, and `tests/wasi/ScriptHostAxioms.lean` audits its theorems.
