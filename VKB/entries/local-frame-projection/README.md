# Equality and projections of raw Wasm locals

The entry applies to proofs that step through Wasm code with Talos's `wp` rules and must reason about `Wasm.Locals`: the parameters, the internal locals, and the operand stack of a Talos frame.  The lemmas of `LeanExe/ProofKit/Frame.lean` serve proofs of hand-written code, such as the runtime's `alloc` and `release`.  The proofs of the verified compiler's generated code use the lemmas of `Verified/LocalFrame.lean` for the same facts, and `Verified.Frame` there relates the locals before and after an expression's code position by position.

Talos's `Wasm.Locals` has no extensionality theorem of its own.  `Frame.ext`, tagged `@[ext]`, proves two frames equal from equal parameter lists, internal-local lists, and operand stacks, either applied to the three equations or through `ext <;> simp_all` when they follow from the context.  The runtime's proofs use it as `Frame.ext _ _ rfl rfl hValues.symm`, from `hValues : frame.values = []`, to show that `{ frame with values := [] }` is `frame`, so that a rule stated for a frame with an empty operand stack applies, and `Frame.of_withValues` packages that step for any operand stack.

`Frame.withValues_get`, `Frame.withValues_params`, `Frame.withValues_locals`, and `Frame.withValues_values` give the fields of `{ frame with values := vs }` after a block, branch, or call rule replaces only the operand stack, and `Verified.Locals.get_values` is the verified compiler's form of `withValues_get`.  Prefer them to unfolding `Wasm.Locals.get`, a `simp` definition whose unfolding splits on whether the index is a parameter or an internal local.  The verified compiler's proofs write a store to an internal local as `Verified.setLocal`, which `Verified.Locals.set?_local` relates to Talos's `Locals.set?`, and read it back with `Verified.Locals.get_setLocal_same` and `Verified.Locals.get_setLocal_ne`.

For repeated stores that keep a different index, `List.getElem?_set_ne` with the index inequality avoids the `if` that `simp` makes of every update, as the proof of `Verified.Locals.get_setLocal_ne` does.  `Frame.parameter_getElem_of_get` turns `frame.get index = some value`, for a parameter index, into `frame.params[index] = value`.  `Frame.internal_getElem?_of_get` and `Frame.internal_getElem_of_get` turn the same fact at index `parameterCount + localIndex` into one about `frame.locals[localIndex]`, from the parameter count and the bound on `localIndex`, for every `Wasm.Value` kind and any number of locals.

`LeanExe.ProofKit.MemoryGrowth.ensureProgram_spec_available`, `LeanExe.ProofKit.FixedArraySearch.guardProgram_spec`, `LeanExe.ProofKit.FixedArrayHeader.writeLocal_specA`, and `LeanExe.Pipeline.joinProgram_spec` each prove one part of `alloc` or `release`, with `wp` or its aligned form `wpA`.  All four close a frame equality with `Frame.ext`, and the first three also rewrite with `Frame.withValues_get`.  They are the models for a proof of further hand-written code.
