GPT-2 in Binary32

GPT-2 124M, greedy decoding. Each token runs the host commands of Project/Gpt32/Program.lean, which generate_host proves compute step32 on a device with strict binary32 arithmetic. WGSL lets a device flush subnormal values to zero and fuse multiplications with additions, and the comparison shows the effect on this one. With WGSL, each kernel call is a WebGPU dispatch of its translated kernel. Without WGSL, it is a call of the same kernel compiled to gpt32.wasm on the CPU. Both together run every step on each and compare the scores bit for bit; the tokens follow Wasm.
