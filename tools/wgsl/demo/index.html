The transformer is compiled from Project.TinyGpt2Seq.hidden into Wasm. The existing generated WGSL shader computes the 4×256 vocabulary projection. Wasm also performs precision conversions, bias addition and greedy next-byte selection. JavaScript loads files, moves bytes, calls the runtimes and updates this page.

The full generated transformer Wasm proof and the small transfer adapter proof are incomplete. The shader and bias-addition artifact have existing proofs. This demo accepts the browser's WebGPU arithmetic behavior; it does not claim exact-profile conformance.
