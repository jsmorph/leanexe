      What the proof covers

      The universal theorem covers every valid input within the 6-job, 8-category limit. It proves termination, agreement with the source program, and the category discrepancy bound for the identified binary. With no memberships, every category count is zero. Group sizes can differ.

      The proof assumes a represented input, valid allocator state, and sufficient memory, including a conservative allocation budget of 223,756,952 bytes. The browser, JavaScript adapter, and counts display are outside the Lean proof.

      The server checks the binary’s SHA-256 before serving it. Each run uses a fresh browser worker. The page independently checks the returned overlap, assignments, and category differences.
