A job can belong to several categories. If each job belongs to at most t categories, the two groups’ counts differ by at most 2t − 1 in every category.

      Verification status and limits

      Lean checks arbitrary-length integer addition, subtraction, multiplication, comparison, and the rounding argument over arbitrary finite job and category sets. Division, the connection from elimination to rounding, resource bounds, and the exact-binary execution theorem remain in progress.

      The page recomputes every category count and checks the discrepancy bound. Native Lean and WASM comparisons include overlapping inputs with up to 128 jobs. Supported resource limits still require a proof. The browser editor allows 128 jobs and 32 categories. Each run has a 30-second timeout.

      The server checks the binary against its build manifest. Each run uses a fresh worker and reports its elapsed time and WASM memory extent.
